# Institute App (Our School App)

A modern, high-performance React Native and Expo Web mobile application built for schools and educational institutes.

## Tech Stack
- Expo SDK 52 / Expo Router v4
- TypeScript
- React Native / StyleSheet Design System
- Expo Print & Custom Universal PDF Exporter

## Development & Build Commands
- `npm run dev` (starts Metro bundler)
- `node server.js` (starts web preview server on port 8081)
- `npx expo export --platform web` (builds static production web bundle)
